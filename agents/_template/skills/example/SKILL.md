# Example Skill

Replace this file. A skill is one repeatable workflow:

- **When to use it** - the trigger condition, in the user's terms.
- **What it produces** - the artefact the workflow ends with.

## 1. Gather the inputs

List what the workflow needs and where each input comes from. If an input is
missing, say what to do instead of guessing.

## 2. Do the work

The steps. Keep them explicit enough that another agent could follow them.

## 3. Check the result

A short checklist the agent applies before returning anything:

- does the output match what was asked for,
- is every claim traceable to an input,
- is anything left unsaid.
