# Product

A product manager agent skilled in product strategy, user research, PRD writing, roadmap prioritization, Figma design review, feature acceptance, and launch planning.

## Install

```bash
acowork install com.acowork.product-manager
```

Or download the signed `.agent` package from the hub and import it in
the Desktop App. The package is signed by the official channel key —
the app verifies the signature on install.

## What it does

- **feature acceptance** — Validate implemented features against PRD, Figma, acceptance criteria, metrics, and release readiness
- **figma design review** — Review Figma designs for product intent, user flow, UX clarity, states, accessibility, and engineering handoff readiness
- **launch planning** — Plan product launches with rollout, communication, analytics, support readiness, risks, and post-launch learning
- **prd writing** — Write product requirements with problem framing, user stories, acceptance criteria, metrics, and non-goals
- **product strategy** — Define product vision, target users, positioning, goals, bets, and success metrics
- **roadmap prioritization** — Prioritize roadmap items using evidence, impact, effort, confidence, risk, and strategic alignment
- **user research** — Plan and synthesize user research, interviews, personas, journeys, and opportunity areas
