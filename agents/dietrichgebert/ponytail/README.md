# Ponytail

The best code is the code you never wrote.

## Install

```bash
acowork install github.ponytail
```

Or download the signed `.agent` package from the hub and import it in
the Desktop App. The package is signed by the official channel key —
the app verifies the signature on install.

## What it does

- **architecture design** — Design system architecture with module breakdown and interface definitions
- **code review** — Perform a thorough code review with actionable feedback
- **debug assist** — Debug and troubleshoot issues with systematic root-cause analysis

## Permissions

Read them before you install:

- `FilesystemRead`
- `FilesystemWrite`
- `Network`
- `Shell`
