The registry could not be loaded

The registry data is generated by the release pipeline and served as shards (data/meta.json → data/pages/). The page deliberately embeds no copy of it, so it must be served over HTTP — for example python -m http.server in the built site directory. file:// cannot load the shards.

Publish an agent

The hub takes pull requests. You keep the source; the pipeline builds, signs and publishes the package for you. 

git clone https://github.com/acowork/ACoworkAgentHub.git
cd ACoworkAgentHub
cp -r agents/_template agents/your-name/your-agent
python tools/validate.py
